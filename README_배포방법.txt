IN & OUT 웹 배포 안내

1. GitHub에서 새 Public repository를 만듭니다. 예: in-and-out
2. 이 ZIP을 풀고 index.html, sample.json, output_pilot_6.json 파일을 저장소 최상위(root)에 업로드합니다. ZIP 자체를 업로드하면 안 됩니다.
3. 저장소 Settings > Pages > Build and deployment에서 Source를 Deploy from a branch로 선택합니다. Branch main, folder /(root)를 선택하고 Save합니다.
4. Pages에 표시된 웹 주소로 접속합니다. 배포 반영까지 몇 분 걸릴 수 있습니다.
5. Chrome에서 마이크 사용을 허용하면 음성인식 기능을 시험할 수 있습니다. 브라우저에 따라 음성인식 지원 여부가 다릅니다.

주의: 학습 기록은 현재 각 기기의 브라우저 localStorage에 별도로 저장됩니다. 여러 기기에서 자동 동기화되지 않습니다. GitHub Pages 공개 저장소에는 개인정보나 비공개 학습 자료를 올리지 마세요.
